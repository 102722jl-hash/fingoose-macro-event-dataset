# FinGoose 研究工作台界面重构设计

## 目标

将十事件快速候选版从“事件页集合”重构为一个可连续阅读的中文投研工作台：左侧固定十事件导航，右侧显示所选事件的完整研究链路；时间线节点、动态传导边、行情窗口、证据链接和混杂解释相互联动。

## 设计方向

采用已确认的 A 方案“高密度投研工作台”，并采用联动长页面而非顶部标签切换。右侧页面顺序为：事件摘要、证据时间线、动态传导链、行情验证、证据摘录、混杂与竞争解释。点击时间线节点后，页面滚动至对应传导边和行情窗口，并在三处增加选中状态。

## 页面结构

- 固定左侧栏：FinGoose 标识、版本状态、十个事件入口、每个事件的节点数/待补证数/混杂等级；移动端改为顶部可横向滚动事件选择器。
- 右侧主区：事件标题、研究状态、主锚点、节点/路径/行情统计，以及“当前选择”上下文条。
- 时间线：按阶段分组显示“前置背景、首次冲击、升级、政策响应、缓和、二次冲击”；每个节点显示日期、事实、影响标签、证据状态、原始引文摘录和证据链接。
- 动态传导链：每条路径拆成四个可视节点“冲击类型 → 统一渠道 → 事件专属中间变量 → 资产”；显示即时/短期/中期方向、时滞、激活阶段、成立条件、失效条件、反证和证据范围。点击路径或时间线节点时互相高亮；PENDING 节点不得显示为可评分边。
- 行情验证：每个核心序列显示 T-1、T0、D1、D3、D5、D20 的绝对值、原始变化、标准化变化、日期和计算口径；用原生 SVG 折线图绘制同一序列的窗口走势，标注 T0 与 D1 同日别名，混杂窗口用色带标识。
- 证据摘录：按“事实与时间 / 机制补充 / 混杂证据”分组；展示中文摘要、原文引用、来源机构、定位信息和外链，机制来源明确标注“事后机制验证，不用于事前预测”。
- 混杂与竞争解释：每个事件至少展示一段 180-350 字中文论证，说明竞争冲击何时进入、影响哪些窗口、为何不能把全部变化归于主事件，并列出可反驳观察和相关证据链接。文字必须来自数据字段或明确的中文派生模板，不凭空添加事实。

## 中文化规则

- UI 标签、阶段、状态、资产角色、窗口、证据范围全部中文化。
- 事件事实保留来源原文语义，但提供中文研究摘要；英文原文只放在可展开的“原文引文”区域。
- 状态映射：`VERIFIED_EXISTING` 显示“已有证据”，`PENDING_EVIDENCE` 显示“待补证”，`PROPOSED` 显示“候选路径”，`CORE_REVIEWED` 显示“核心复核”，`CHALLENGE_ONLY` 显示“仅作挑战集”。
- 任何缺失日期、引文或来源链接显示“未知/待补证”，不使用推测值。

## 视觉与交互

- 视觉基调为冷白、墨绿、砖红、琥珀状态色，保持高对比和研究工具感；避免渐变、装饰性大卡片和过度圆角。
- 左栏宽度 248px，主区最大宽度 1280px；卡片只用于单个路径、证据或混杂条目，页面分区保持无外框。
- 时间线节点和传导边使用稳定尺寸；图表采用响应式 `viewBox`，桌面与移动端均不改变数据比例。
- 所有图标按钮提供 `title`/`aria-label`；外链使用 `target="_blank" rel="noopener noreferrer"`。
- 移动端：左栏转为顶部抽屉，时间线和传导链单列，行情表格允许横向滚动但不遮挡标题或数值。

## 数据流与边界

- 生成器继续从现有 `timeline_nodes.jsonl`、传导路径、行情窗口、来源台账和混杂配置构建页面，不修改生产 v1/v2 数据。
- 新增的中文标签、证据摘要和论证段落作为生成器中的受控派生映射；保留原始字段用于追溯。
- 图表只使用已有 `display_windows` 绝对值；缺值保持断点，不插值。
- 时间线点击只改变前端选中状态，不改变证据状态、评分资格或数据文件。
- `formal_ready` 继续为 `false`，8 个待补证节点继续禁止进入评分路径，35 条路径继续为 `PROPOSED`。

## 验收标准

- 总览页和十个事件均使用左侧事件导航，点击后右侧内容无整页刷新。
- 每个事件至少有 5 个时间线节点、4 条动态传导路径、4 个核心行情序列和证据外链。
- 时间线节点、传导边、行情图和证据卡片可通过 `data-*` ID 相互定位和高亮。
- 绝对值与变化的公式、日期、T0/D1 别名及混杂色带可见。
- 页面所有用户可见文本为中文；原文引文为折叠内容。
- 桌面宽度 1440px、移动宽度 390px 下无文字遮挡、溢出或空白图表。
- 既有 25 项回归测试继续通过，并新增页面结构、中文化、图表路径和联动状态测试。
