# 行业研究闭环 v3 设计

## 目标

在现有宏观事件研究工作台的“行业影响”区域内补全研究闭环，不创建独立问答产品，也不改变候选包的人工审核状态。本轮依次交付：七步链逐节点证据状态、证据 ID 与原文双向联动、标准事件研究与稳健性检验、行业—公司联动矩阵。

## 数据约束

- 十个事件、七十七个行业映射全部覆盖。
- 每个行业机制链必须保持七个节点，不把事件锚点证据扩张为整条链的证明。
- 节点状态限定为 `VERIFIED_SOURCE`、`SUPPORTED_INFERENCE`、`INFERENCE_ONLY`、`EVIDENCE_MISSING`。
- 证据登记表必须能从证据 ID 找到原文、定位、URL、SHA 和支持的机制步骤；缺证 ID 仅显示缺口，不生成伪链接。
- 行情仅使用候选包已有的 T-20 至 D20 连续窗口，不进行事后样本选择。
- event-07 可展示计算结果，但保持截止日门禁，拒绝把截止日后信息解释为可用归因证据。

## 事件研究

先由指数点位计算行业和沪深 300 日收益。简单异常收益为行业收益减市场收益；市场模型在 T-20 至 T-2 估计 `industry = alpha + beta * market + residual`。输出 PRETREND、EVENT、SHORT、MEDIUM 四个窗口的样本数、简单 CAR、市场模型 CAR、平均异常收益、波动率、t 值和方向。

稳健性包括：事件前滚动双日窗口安慰剂、事件窗口绝对 CAR 百分位、两种模型方向一致性，以及事件前趋势污染提示。所有结果均标注“统计验证不证明因果”。

## 界面

行业详情采用紧凑研究工作区：顶部显示七步证据覆盖和事件研究摘要，中部为可点击的七步链与证据原文，下部为四窗口结果和稳健性说明。行业—公司矩阵放在行业区域内，点击行业切换当前行业详情，点击公司跳转到现有公司区域。

移动端允许矩阵容器内部横向滚动，但页面本身不得横向溢出。原时间线、传导链、行业图表、混杂因素、公司详情和研究问答继续保留。

## 发布边界

不新增人工审核操作，不改变 `PROPOSED / NEEDS_HUMAN_REVIEW / formal_ready=false / sha_gate=DEFERRED`。页面不输出买卖建议，不泄漏评测字段。
