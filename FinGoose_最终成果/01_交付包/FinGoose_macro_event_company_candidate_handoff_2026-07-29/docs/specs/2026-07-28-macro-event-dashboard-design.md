# FinGoose 宏观事件归因仪表盘设计

## 目标

为 `outputs/fingoose_macro_event_attribution_v1` 提供只读的内部审计仪表盘，将正式版数据集的发布状态、事件行情、归因推理链和审核闭环集中展示。仪表盘面向不熟悉原始 JSONL 文件的使用者，默认展示隐藏归因标签和 D20 实际结果，并明确标记这些内容不得进入公开训练投影。

## 范围

- 展示 10 个事件、40 条归因样本、40 组市场窗口、隐藏结果与审核记录。
- 提供数据集概览、事件分析和审核记录三个视图。
- 支持按事件、年份、类别、任务类型、最终标签和置信度筛选。
- 不修改正式数据文件，不提供审核写入功能。
- 不修改或依赖 `outputs/fingoose_formal_v1_macro`。
- 不合并现有 `fingoose_macro_audit_ui_v1.py`，避免与 100 条候选数据的字段和审核语义混淆。

## 视觉语言

参考 `dataset-composition-dashboard.html` 的深色数据分析界面：墨绿背景、薄边框面板、绿色发布状态、琥珀色审计警示和紧凑数据图表。界面保持工作台密度，卡片圆角不超过 8px，不使用装饰性光球或大面积渐变。

第一屏必须显示数据集本身和核心发布状态。标题使用 `FinGoose 宏观事件归因`，顶部同时显示版本和 `FORMAL READY`。页面在桌面端采用十二列网格，在移动端转为单列，固定格式图表使用明确的高度和宽高比，避免加载内容导致布局跳动。

## 信息架构

### 数据集概览

- 五个核心指标：事件数、样本数、市场窗口数、完成复审数、完成裁决数。
- 最终标签分布环形图。
- 审核完成情况和复审触发情况。
- 事件年份与类别分布。
- 六阶段推理链覆盖状态。

### 事件分析

- 左侧按时间列出事件，可按年份和类别筛选。
- 主区域展示事件标题、时间、阶段、候选渠道和来源数量。
- 行情图按计量单位分组展示 D1、D3、D5、D20、M3 变化；同时显示异常分数和基线值。
- 六阶段推理链展示宏观研报、可见数据截止、期间描述、事实传导节点、多重趋势确认和短期预测。
- 事件下方展示三条单资产题和一条跨资产题，可继续进入样本详情。

### 审核记录

- 样本表格支持搜索与标签、置信度、任务类型筛选。
- 右侧详情展示最终标签、四个核心归因维度、初审、复审触发原因、复审和裁决。
- 隐藏归因标签和 D20 实际结果置于带有 `内部审计` 标识的区域。
- 公开训练投影字段单独列出，帮助使用者确认公开与隐藏边界。

## 架构

新增 `fingoose_macro_event_dashboard_v1.py`，沿用项目现有 `ThreadingHTTPServer` 模式。模块包含：

- `MacroEventDashboardRepository`：加载并关联正式 JSON/JSONL 产物，提供稳定的查询结果。
- `make_handler`：暴露只读 JSON API 和首页 HTML。
- `INDEX_HTML`：原生 HTML、CSS、JavaScript 与内联 SVG 图表，不增加第三方前端依赖。
- `main`：接受 `--output-root`、`--host` 和 `--port`，默认读取正式事件归因输出。

API 包含：

- `GET /api/overview`
- `GET /api/events`
- `GET /api/event/{event_id}`
- `GET /api/samples`
- `GET /api/sample/{record_id}`

所有路径由服务器配置决定，浏览器不能提交任意文件路径。未知事件或样本返回 HTTP 404；缺失必需产物时服务器启动失败并给出具体文件名，记录中可选字段缺失时前端显示“数据不可用”。

## 数据关联

`event_id` 连接事件档案、市场窗口和样本；`record_id` 连接样本、公开投影、隐藏归因标签和隐藏预测结果；`review_id` 连接审核记录。概览统计从当前文件内容重新计算，并与 `summary.json` 一起返回，便于发现产物不一致。

市场变化的单位直接取 `change_unit`，百分比、基点和汇率结果不得在同一数值轴上混合。隐藏 D20 实际结果只能在内部审计区域渲染，不放入公开投影视图。

## 测试与验收

- 单元测试覆盖文件加载、关联、筛选、概览计算和缺失文件错误。
- HTTP 测试覆盖首页、五类 API 和 404。
- 页面结构测试确认三个主视图、内部审计警示、行情图容器和六阶段推理链存在。
- Playwright 在桌面与移动端检查页面无横向溢出、文字不重叠、图表非空、筛选与详情选择可交互。
- 完成时运行仪表盘专项测试和项目全量测试。
- 启动本地服务器并向使用者提供 URL。

## 非目标

- 不提供数据编辑、审核提交、身份认证或远程部署。
- 不重新计算正式市场窗口和归因标签。
- 不展示公司季度收入或利润预测。
- 不修改现有候选数据审计 UI、行业覆盖 UI 或旧版正式宏观产物。
