01 与「用大模型直接生成财经问答」的区别

面试第一句话就该点出的钩子：它的核心不是「生成了多少条数据」，而是「每条数据能不能被审计」。

维度普通 LLM 生成数据本项目
数字 / 来源模型「记得」、可能编造每条结论挂 source_ref + 快照 SHA-256 + 原文定位符
因果归因顺口就给因果四级因果识别，非 IDENTIFIED 必须 ABSTAIN
事后诸葛隐含未来信息预测截止 = 事件后第 3 个可交易日；D20 进 hidden 层，公开仅见 D1/D3
缺失值补 0 / 猜一个KEEP_NULL_NEVER_ZERO_IMPUTE（fail-closed）
数据契约靠约定21 个 JSON Schema 硬约束 + 16 项验证门禁
交付质量人肉抽查VERIFY_HANDOFF.ps1 遍历 201 个文件逐一 SHA-256，输出 HANDOFF VERIFIED

03 核心机制

本项目的第一加分项：把「因果」变成「可校验的数据契约」。

Schema 驱动 + fail-closed

先定义 21 个 JSON Schema 数据契约，再由 100+ 构建器逐层「填」、校验器逐层「守」。非合规样本不降级、不补值，直接 ABSTAIN。157 条样本全部 CLOSED，missing_node=0、open_closure=0、placeholder=0（三个零）。

抗 look-ahead 的物理隔离

visible_windows 硬编码 const ["D1","D3"]、hidden_outcome_window 硬编码 const "D20"；双时钟时间政策区分 AS_OF_EVIDENCE / POST_EVENT_VALIDATION / CUTOFF_BLOCKED，只有 as-of 证据能支持预测。

事件级切分防泄漏

按 sha256_mod_100 分桶切分（train=event-01~08 / validation=event-09 / test=event-10，124 / 16 / 17），避免同一事件样本跨集泄漏导致指标虚高。

可审计、可复现

每条结论可回溯到原文定位符（如 locator="page=1, HIGHLIGHTS, bullet 1"）+ 快照 SHA；SNAPSHOT_PATH_MAP.csv（47 行）全部 HASH_MATCHED；同输入重建 → 相同 SHA-256。

诚实的质量观

市场归因 v1 中 UNSUPPORTED=18/40（45%）、公司因果识别 NOT_IDENTIFIED=30——承认「没有可支撑因果」恰恰是数据集的价值，而不是缺陷。

工程门禁齐全

validate_dataset.py → 0 errors / 0 warnings；pytest training/tests → 46 passed；发布门禁 11 条 + 因果门禁 8 项 + 四角色人工审查制度。

05 已知局限（诚实声明）

  1. 商品集 v0.2 status=blocked：四商品（CU/AU/SC/I）未全部完成。
  2. 公司因果识别全部 NOT_IDENTIFIED（30 条）→ 公司结论必须 ABSTAIN；公司候选集 formal_ready=false。
  3. 传导边为 AI 生成 PROPOSED，未人工确认；v2 aggregate_score=null。
  4. 行业市场数据缺口：申万指数 / 沪深300 历史在许可库中不可用。
  5. 训练未真正执行：--dry-run 仅 ready=true、model_loaded=false。
  6. 部分来源抓取失败保留 FETCH_FAILED（拒绝用搜索摘要冒充实证）。
